BERTINDAKLAH SEBAGAI: 1. Guru IPAS SD yang memahami Kurikulum Merdeka. 2. Ahli instructional design untuk pembelajaran sekolah dasar. 3. Web developer profesional yang menguasai HTML5, CSS3, dan JavaScript. 4. UI/UX designer khusus media pembelajaran anak SD. 5. Pengembang media pembelajaran interaktif yang dapat digunakan pada HP, tablet, dan laptop. ======================================================== A. PERSONA ======================================================== Saya adalah guru kelas 4 SD yang mengajar mata pelajaran IPAS. Saya ingin membuat media pembelajaran interaktif untuk peserta didik kelas 4 SD dengan materi: "AKAR DAN FUNGSINYA" Elemen: "PEMAHAMAN IPAS" Karakteristik peserta didik: - Usia sekitar 9–10 tahun. - Senang belajar melalui gambar, animasi, permainan, kuis, dan aktivitas interaktif. - Membutuhkan bahasa yang sederhana dan mudah dipahami. - Memiliki kemampuan belajar yang beragam. - Sebagian peserta didik menggunakan HP. - Sebagian peserta didik menggunakan laptop. - Media harus dapat digunakan secara individu maupun bersama-sama di kelas. Gunakan Bahasa Indonesia yang: - sederhana; - komunikatif; - sesuai usia peserta didik kelas 4; - tidak terlalu banyak istilah ilmiah; - tetap menggunakan istilah IPAS yang benar. ======================================================== B. TUGAS UTAMA ======================================================== Buat MEDIA PEMBELAJARAN INTERAKTIF IPAS KELAS 4 dengan topik: "AKAR DAN FUNGSINYA" Tujuan pembelajaran: Setelah menggunakan media pembelajaran ini, peserta didik diharapkan mampu: 1. Mengenal bagian akar pada tumbuhan. 2. Menjelaskan pengertian akar dengan bahasa sederhana. 3. Mengidentifikasi fungsi akar. 4. Menjelaskan fungsi akar dalam menyerap air dan mineral dari tanah. 5. Menjelaskan fungsi akar dalam menopang tumbuhan. 6. Mengenal beberapa jenis akar. 7. Membedakan akar tunggang dan akar serabut. 8. Memberikan contoh tumbuhan yang memiliki akar tunggang. 9. Memberikan contoh tumbuhan yang memiliki akar serabut. 10. Menghubungkan bentuk akar dengan fungsi tumbuhan dalam kehidupan sehari-hari. 11. Menyelesaikan permainan dan kuis tentang akar dan fungsinya. 12. Menyimpulkan pentingnya akar bagi tumbuhan. ======================================================== C. FORMAT MEDIA ======================================================== Buat media dalam bentuk: "SINGLE PAGE INTERACTIVE LEARNING WEBSITE" Gunakan: - HTML5 - CSS3 - JavaScript Vanilla Jangan menggunakan framework yang berat. Media harus dapat: - dibuka melalui Google Chrome; - dibuka melalui Microsoft Edge; - dibuka melalui Firefox; - digunakan pada HP Android/iPhone; - digunakan pada tablet; - digunakan pada laptop/komputer; - responsive; - tidak menyebabkan tampilan terpotong; - tidak membutuhkan instalasi aplikasi tambahan. Buat seluruh media dalam satu file: index.html CSS dan JavaScript dapat berada di dalam file tersebut. ======================================================== D. IDENTITAS MEDIA ======================================================== Pada bagian header tampilkan: MEDIA PEMBELAJARAN INTERAKTIF IPAS "AKAR DAN FUNGSINYA" KELAS 4 SD "SD NEGERI 005 SINGKEP" Guru: "TRI WAHYUNI, S.Pd" Tambahkan ilustrasi tumbuhan yang menarik dan ramah anak. ======================================================== E. MENU UTAMA ======================================================== Buat menu utama berupa kartu/tombol: 🏠 BERANDA 🎯 TUJUAN PEMBELAJARAN 🌱 MARI BELAJAR 🔍 EKSPLORASI AKAR 🎮 PERMAINAN 📝 LATIHAN 📚 KUIS 💡 REFLEKSI 📊 HASIL BELAJAR 📖 GOOGLE DOCS 📊 GOOGLE SHEETS ======================================================== F. HALAMAN BERANDA ======================================================== Tampilkan: "HALO, SAHABAT IPAS! 🌱" "Yuk, kita mengenal akar dan mengetahui berbagai fungsi akar bagi tumbuhan." Tambahkan tombol: "MULAI BELAJAR" Ketika tombol diklik, peserta didik diarahkan ke bagian tujuan pembelajaran. Tambahkan animasi ringan pada gambar tanaman. ======================================================== G. TUJUAN PEMBELAJARAN ======================================================== Tampilkan tujuan pembelajaran dalam bentuk kartu. Gunakan kalimat sederhana. Contoh: "Setelah belajar, kamu dapat:" ✓ Mengenal akar. ✓ Menjelaskan fungsi akar. ✓ Mengenal jenis-jenis akar. ✓ Membedakan akar tunggang dan akar serabut. ✓ Menyebutkan contoh tumbuhan. ✓ Menjawab pertanyaan tentang akar. Tambahkan tombol: "SAYA SIAP BELAJAR!" ======================================================== H. MATERI PEMBELAJARAN ======================================================== Buat materi secara bertahap. MATERI 1: "APA ITU AKAR?" Jelaskan: Akar adalah bagian tumbuhan yang umumnya berada di dalam tanah dan berfungsi untuk membantu tumbuhan hidup dan tumbuh. Gunakan ilustrasi tumbuhan dengan bagian akar yang terlihat. Buat tombol: "LIHAT AKARNYA" Ketika tombol diklik, bagian akar pada gambar diberi animasi/highlight. -------------------------------------------------------- MATERI 2: "FUNGSI AKAR" Jelaskan fungsi akar dengan kartu interaktif: 1. 💧 Menyerap air 2. 🧂 Menyerap mineral/zat hara 3. 🌳 Menopang tumbuhan 4. 🌱 Menyimpan cadangan makanan pada tumbuhan tertentu Setiap kartu ketika diklik menampilkan penjelasan sederhana. Contoh: "AKAR MENYERAP AIR" Akar membantu tumbuhan mendapatkan air dari dalam tanah. -------------------------------------------------------- MATERI 3: "JENIS-JENIS AKAR" Jelaskan: A. AKAR TUNGGANG Ciri: - memiliki satu akar utama yang besar; - akar utama dapat memiliki cabang-cabang kecil. Contoh: - mangga; - jambu; - jeruk; - kacang-kacangan tertentu. B. AKAR SERABUT Ciri: - terdiri dari banyak akar kecil; - ukuran akar relatif hampir sama; - tidak memiliki satu akar utama yang dominan. Contoh: - padi; - jagung; - rumput; - kelapa. Gunakan ilustrasi visual yang jelas. ======================================================== I. EKSPLORASI AKAR INTERAKTIF ======================================================== Buat fitur: "🔍 AYO EKSPLORASI!" Tampilkan gambar tanaman. Peserta didik dapat mengklik: BATANG DAUN BUNGA AKAR Ketika peserta didik mengklik AKAR: Tampilkan: "Ini adalah akar." Kemudian tampilkan: - posisi akar; - fungsi akar; - jenis akar; - contoh tumbuhan. Buat animasi sederhana berupa garis/panah yang menunjuk bagian akar. ======================================================== J. FITUR "TEBAK JENIS AKAR" ======================================================== Buat permainan: "AKAR TUNGGANG ATAU AKAR SERABUT?" Tampilkan gambar/nama tumbuhan. Contoh: 🌳 Mangga Pilihan: [Akar Tunggang] [Akar Serabut] Jika benar: "Hebat! Jawabanmu benar! 🌟" Jika salah: "Coba lagi. Perhatikan bentuk akarnya." Berikan skor. Buat minimal 10 pertanyaan. Contoh tumbuhan: - mangga; - jambu; - jeruk; - padi; - jagung; - kelapa; - rumput; - kacang tanah; - wortel; - singkong. ======================================================== K. PERMAINAN MENCARI FUNGSI AKAR ======================================================== Buat permainan mencocokkan. Kolom A: 💧 Menyerap air 🌱 Menopang tumbuhan 🧂 Menyerap mineral 🍠 Menyimpan cadangan makanan Kolom B: Penjelasan fungsi. Peserta didik mencocokkan pasangan yang benar. Untuk HP, sediakan alternatif: "Klik fungsi → klik jawabannya" sehingga tidak hanya bergantung pada drag-and-drop. ======================================================== L. PERMAINAN "SIAPA AKU?" ======================================================== Tampilkan pertanyaan: "Aku berada di dalam tanah. Aku membantu tumbuhan berdiri tegak. Aku juga membantu menyerap air. Siapakah aku?" Pilihan: A. Daun B. Batang C. Akar D. Bunga Jika benar: "Benar! Aku adalah AKAR! 🌱" ======================================================== M. KUIS INTERAKTIF ======================================================== Buat kuis sebanyak: 15 soal pilihan ganda. Setiap soal memiliki: A. B. C. D. Materi mencakup: - pengertian akar; - fungsi akar; - penyerapan air; - penyerapan mineral; - menopang tumbuhan; - menyimpan cadangan makanan; - akar tunggang; - akar serabut; - contoh akar tunggang; - contoh akar serabut; - fungsi akar dalam kehidupan tumbuhan. Soal ditampilkan satu per satu. Tampilkan: "SOAL 1 DARI 15" Buat progress bar. Peserta didik memilih jawaban. Setelah menjawab: - tampilkan feedback; - jelaskan jawaban yang benar; - lanjutkan ke soal berikutnya. Jangan langsung menampilkan semua soal. ======================================================== N. HASIL KUIS ======================================================== Setelah selesai, tampilkan: HASIL BELAJARMU 🎉 Nama: Kelas: Tanggal: Skor: Jumlah benar: Jumlah salah: Persentase: Predikat: Gunakan predikat: 90–100 = Sangat Baik 80–89 = Baik 70–79 = Cukup <70 = Perlu Bimbingan Berikan kalimat motivasi. Contoh: "Hebat! Teruslah belajar dan mengenal lebih banyak tentang tumbuhan." Untuk nilai rendah, jangan menggunakan kata-kata yang menyalahkan. Contoh: "Ayo belajar lagi. Kamu pasti bisa memahami materi ini dengan lebih baik!" ======================================================== O. FORM DATA PESERTA DIDIK ======================================================== Sebelum memulai kuis, tampilkan formulir: Nama Peserta Didik Kelas Tanggal Jangan meminta: - alamat; - nomor telepon; - password; - data pribadi yang tidak diperlukan. ======================================================== P. REFLEKSI ======================================================== Setelah kuis, tampilkan: "💡 AYO REFLEKSI!" Pertanyaan: 1. Apa fungsi akar bagi tumbuhan? 2. Apa perbedaan akar tunggang dan akar serabut? 3. Sebutkan dua tumbuhan yang memiliki akar tunggang. 4. Sebutkan dua tumbuhan yang memiliki akar serabut. 5. Mengapa akar penting bagi tumbuhan? Sediakan kotak teks agar peserta didik dapat mengetik jawabannya. Tambahkan tombol: "SIMPAN REFLEKSI" ======================================================== Q. INTEGRASI GOOGLE SHEETS ======================================================== Buat sistem untuk mengirim hasil belajar ke Google Sheets menggunakan: Google Apps Script Web App. Data yang dikirim: - Timestamp - Nama Peserta Didik - Kelas - Tanggal - Skor - Jumlah Benar - Jumlah Salah - Persentase - Predikat - Jawaban Refleksi Buat konfigurasi: const GOOGLE_SCRIPT_URL = "MASUKKAN_URL_GOOGLE_APPS_SCRIPT_DI_SINI"; Jangan membuat URL palsu. Guru akan mengganti placeholder tersebut dengan URL Google Apps Script miliknya. Ketika peserta didik menekan: "SIMPAN HASIL" kirim data menggunakan JavaScript fetch(). Jika berhasil tampilkan: "✅ Hasil belajar berhasil disimpan." Jika gagal tampilkan: "⚠️ Hasil belum berhasil dikirim. Silakan periksa koneksi internet." ======================================================== R. FORMAT GOOGLE SHEETS ======================================================== Buat struktur spreadsheet: | Timestamp | Nama | Kelas | Tanggal | Skor | Benar | Salah | Persentase | Predikat | Refleksi | Buat Google Apps Script lengkap untuk menerima data dari HTML. Gunakan: doGet(e) dan doPost(e) sesuai kebutuhan. Pastikan Apps Script dapat menerima data JSON dari JavaScript. ======================================================== S. GOOGLE DOCS ======================================================== Tambahkan tombol: "📖 BUKA MATERI LENGKAP" Gunakan variabel: const GOOGLE_DOCS_URL = "MASUKKAN_LINK_GOOGLE_DOCS_DI_SINI"; Ketika tombol ditekan: window.open(GOOGLE_DOCS_URL, "_blank"); Google Docs dapat digunakan guru untuk menyimpan: - materi; - LKPD; - rangkuman; - tugas; - bahan bacaan. ======================================================== T. GOOGLE SHEETS ======================================================== Tambahkan tombol: "📊 LIHAT HASIL BELAJAR" Gunakan: const GOOGLE_SHEETS_URL = "MASUKKAN_LINK_GOOGLE_SHEETS_DI_SINI"; Ketika tombol diklik: window.open(GOOGLE_SHEETS_URL, "_blank"); ======================================================== U. MODE HP DAN LAPTOP ======================================================== Pastikan desain responsive. Untuk HP: - tombol besar; - teks tidak terlalu kecil; - kartu tersusun satu kolom; - tidak ada horizontal scrolling; - drag-and-drop memiliki alternatif klik. Untuk tablet: - gunakan dua kolom jika memungkinkan. Untuk laptop: - gunakan layout lebih lebar; - menu tetap mudah digunakan; - materi dan ilustrasi dapat ditampilkan berdampingan. Gunakan CSS: @media (max-width: 768px) { ... } @media (max-width: 480px) { ... } ======================================================== V. FITUR TAMBAHAN ======================================================== Tambahkan: 1. 🔊 Tombol "Dengarkan Materi" Gunakan Web Speech API jika tersedia. 2. 🌙 Mode malam. 3. 🔄 Tombol ulangi permainan. 4. 🏠 Kembali ke beranda. 5. 📈 Progress pembelajaran. 6. 🌟 Animasi bintang ketika jawaban benar. 7. Feedback positif. Jangan menggunakan suara otomatis ketika halaman pertama kali dibuka. ======================================================== W. AKSESIBILITAS ======================================================== Pastikan: - tulisan mudah dibaca; - kontras cukup; - tombol dapat digunakan dengan sentuhan; - tombol memiliki label yang jelas; - navigasi dapat menggunakan keyboard; - jangan hanya menggunakan warna untuk menunjukkan jawaban benar/salah; - gunakan simbol atau teks tambahan. ======================================================== X.
